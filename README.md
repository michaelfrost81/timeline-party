# Timeline Party

En live multiplayer webapp til musik-tidslinjespil.

## Kør lokalt
1. Installer Node.js.
2. Åbn terminalen i projektmappen.
3. Kør `npm install`
4. Kør `npm start`
5. Åbn `http://localhost:3000`

## Læg online
Projektet kan deployes på fx Render, Railway eller Fly.io. Det kræver Node.js-hosting med WebSocket-support.

Bemærk: Appen er lavet som en generisk musik-tidslinjeplatform. Brug ikke beskyttet Hitster-branding eller kopier ophavsretligt materiale uden tilladelse.
